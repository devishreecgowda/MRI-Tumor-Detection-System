# Dataset

This project uses brain MRI images for tumor classification.

The dataset contains MRI images belonging to the following categories:

- Glioma
- Meningioma
- Pituitary Tumor
- No Tumor

## Dataset Organization

The dataset is organized into separate categories to support image preprocessing, model training, validation, and testing.

## Data Preprocessing

The MRI images are prepared before training using image preprocessing techniques. Depending on the implementation, preprocessing may include resizing, normalization, and data augmentation.

## Note

The dataset is not included in this repository due to its size. Please ensure that the dataset is obtained from its original source and used according to its licensing and usage terms.
